# textbook-writing v3.1.0

本版本在远端 v3.0.0（d81c69a）上整合本机尚未发布的 LaTeX/PDF 功能。保留 v3 的对象绑定、代码—输出检查、修订影响分析、学习者投影、统一 HTML 发布验收和冻结基线，不以旧本地版本覆盖它们。

## 新增

- CI 固定 Ubuntu 24.04，避免 `ubuntu-latest` 升级到 26.04 后与已固定的 Playwright 1.57.0 不兼容；显式 Bash 启用管道失败传播，测试输出经 `tee` 保存时仍可阻止失败发布。
- 新建教材默认交付 TeX 源码闭包与 PDF；已有 HTML 工程及用户指定格式继续沿用。
- 模板优先级为用户指定、现有稿件、随包默认快照。默认模板附 17 个源文件摘要，可离开原作者机器使用。
- 初始化器支持中文 XeLaTeX、英文 pdfLaTeX 及用户模板；保留用户源码字节、入口、宏和字体约定，拒绝覆盖已有目录与符号链接，失败时清理本次暂存目录。
- 保留字面引用的 `.out`、`.log` 等真实源码输入，不按扩展名误删。初始化器不运行模板代码、不编译、不安装依赖。
- TeX/PDF 独立检查编译、引用、字体、版面、代码与源码闭包；HTML 继续使用 TextbookReleaseManifest/v2 和 verify_release.py。创建回执不表示 PDF 或教材验收通过。

## 验证与边界

新增模板初始化回归测试覆盖默认/自定义模板、中文/英文派生、摘要、入口选择、覆盖保护与失败清理。与既有 HTML、真实 KaTeX、Chromium 和 GLS 两轮回归一起执行；实际数量和结果以本 Release 的 validation-evidence.zip 为准。

发布前本地实际编译中英文初始化骨架并检查 PDF。该小样仅验证模板初始化与构建路径，不是完整教材、所有用户模板或数学正确性的认证。CI 证据中的初始化测试本身不执行 TeX 编译。

独立软件审查与教材的数学审稿、学习者评估分别报告；本次没有编写新教材，也不宣称完成教材教学闭环。源代码包保留完整运行资源与测试，不包含私有配置、凭据、依赖缓存或系统字体。
