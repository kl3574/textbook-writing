# textbook-writing v3.0.0

本版本将教材写作要求落实为对象关系、统一验收与可回放版本对照。基线为 v2.2.0，提交 fc1a5c246409b1740145418034fb7eedbcf7ef66。

## 新增与修复

- 统一发布入口，自动推导必须运行的检查；分别报告机械、内容审校、独立教学状态。
- 支持四种公式定界符、公式注册 ID 和未登记数学标记扫描；KaTeX 版本与哈希固定。
- 算例/代码/输出一一绑定；修复同章交换两个输出仍通过的问题。
- 被动笔记属性/URL 允许列表；完整离线浏览器检查组件裁切、图片、错误、答案交互及实际字体声明。
- 定理/证明/来源/习题/解答注册表，依赖循环和失效传播检查；真实删除答案的学习者投影。
- 保留六项写作标准，明确全证明与先修边界；区分充分条件、必要条件和冗余条件。
- 8 类公开行为任务、三条件隔离输入及有日志约束的回执汇总。

## 实际案例与证据范围

GLS 案例实际运行冻结原版和新版检查器：正常输出都通过；故意交换 1.4 和 2 的展示结果时，原版通过，新版报告两个输出错配。该结果是确定性故障回归，不是自然生成教材的错误率估计。

CI 运行原 12 项测试及新增测试、真实 KaTeX 正/反向解析、Chromium 双视口与完整 file:// 导航，并要求案例两轮机械验收通过。实际测试数量与日志见本 Release 的 validation-evidence.zip，源代码包与证据使用同一提交。

模型新旧版盲测、token 收益、人类学习收益、独立教材数学审稿和教学评估没有在本次会话中完成；不虚构其成绩。案例发布回执正确保留独立审校/教学未运行状态。工程测试通过不等于数学零错误认证。

## 兼容性与成本

新版发布采用 TextbookReleaseManifest/v2，因此升至主版本 3。旧 CLI 继续可用，但只产生局部兼容检查。增加 BeautifulSoup、内容注册和审查回执的维护成本；浏览器与 KaTeX 需要显式配置。尚未测得生成 token 或耗时净收益。

保持独立离线交付；可预渲染原生 MathML 并保留 LaTeX，不需要分发字体。代码执行隔离目录与超时不是安全沙箱，只运行已审阅可信代码。
