# textbook-writing

数学/统计教材 HTML 讲义的写作技能：六项正交标准 + 交付前子 agent 教学迭代循环。

适用于估计理论、优化算法等数学/统计课程讲义（HTML）的创建与修订。

## 六项正交标准

每条标准对应一个独立职能，检查清单互不重叠：

| 标准 | 职能 | 要点 |
|---|---|---|
| 正确性 | 数学上对 | 证明无跳步、引用注明、变量就地标注形状、基础工具划界 |
| 符号系统 | 记号统一 | 符号约定表、学界主流锚定、系列一致、LaTeX 包裹 |
| 结构 | 知识组织 | 认知链组织、深度理解五要素（框架/特例/联系/场景） |
| 教学法 | 学得懂 | 日常类比、可手算数值算例、完备反例+反例总览表、习题形式 |
| 验证 | 检验过 | 特例代码实测、子 agent 教学迭代循环 |
| 交付 | 拿得到 | 讲义+习题（解答折叠）HTML、聊天不输出讲义、一次一章 |

## 交付流程

1. 起草：按六项标准写作单章
2. 自审：逐条对照六项标准
3. 联网核实关键事实
4. 教学循环：把完整讲义"教给"子 agent（general-purpose，带网络工具），子 agent 完成三项学习任务——做题（核心定理至少 1 道外部锚点题 + 自出应用题）、找反例（由主会话对照文献判定有效性）、代码实测（运行教材算例代码）
5. 主会话合并反馈、修订教材
6. 重复 4-5 至完成标准：连续 2 轮做题全对 + 无新增有效反例 + 代码实测全部通过
7. 交付

本循环定位为**缺陷发现器**而非质量认证：通过只说明未发现大问题。有效反例的判定由主会话负责，子 agent 只出报告与修改建议、不改文件。

## 安装

- Claude 桌面应用：设置 → Skills → 将 `SKILL.md` 放入 skills 目录（或通过 Save skill 安装）
- 其他支持技能的 Claude 环境：克隆本仓库后配置技能路径指向 `SKILL.md`

## 使用

写作或修订教材章节时引用本技能（如 `/textbook-writing`），Claude 将按六项标准写作并执行交付前验证循环。
